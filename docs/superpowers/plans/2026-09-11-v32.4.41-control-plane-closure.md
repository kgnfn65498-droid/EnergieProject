# 32.4.41 Control Plane Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the repeated watcher/native-MCP control-plane failures structurally, make Chat/Voice/Nomad approval the canonical exact-decision route, and close 32.4 live CR/CLEARUP/hygiene debt without another symptom patch.

**Architecture:** The dedicated `energie-control-plane` container is the only Docker-socket control plane. Projectmanager writes exact approval-gated request envelopes under `Inbox/control_plane/requests`; the control plane executes only `watcher_recreate` and `native_mcp_reload` and writes exact result envelopes/readbacks. PM treats current runtime truth as authoritative so stale restart decisions are superseded rather than executed. The release also persists audit recurrence badges, restores complete timing truth, includes the control-plane in NAS Container CR/restore proof, and keeps development artifacts under one Inbox `Develop` namespace while CLEARUP quarantines stale root-level debris after recovery gates.

**Tech Stack:** Python 3.12+, pytest, JSON runtime envelopes, QNAP Container Station/Docker Engine Unix socket, existing PMV2 persistence/decision/task/CR/CLEARUP modules.

**Spec:** `Data/03_Systeem/Projectmanager/Requirements/HARD_REQUIREMENT_32441_CONTROL_PLANE_AND_HYGIENE.md`

- No Peter Terminal/shell/sudo/Docker commands in the normal flow.
- No fourth watcher/native-MCP symptom patch: dedicated control-plane is the canonical path.
- Protected actions require exact Peter approval; stale decisions are superseded only by machine-verifiable runtime evidence.
- Development mode for build/test; live closure may use MAINTENANCE.
- TDD RED→GREEN for every behavior change.
- CLEARUP remains no-delete quarantine with dependency audit, old-path-absent proof, restore evidence, and fail-closed behavior.

- Every release audit reports badge + true repair-round counter per concrete fault/acceptance issue.
- Final ZIP is exact tested bytes only.
