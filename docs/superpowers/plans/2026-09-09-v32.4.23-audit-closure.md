**Goal:** Build v32.4.23 as the final audit-closure release for month-close safety, certification, roadmap semantics and safe external PM ingress.

**Tech Stack:** Python 3, pytest, Home Assistant add-on HTTP server, PMV2 JSON persistence, HMAC/constant-time secret comparison.

**Spec:** `docs/superpowers/specs/2026-09-09-v32.4.23-audit-closure-design.md`
