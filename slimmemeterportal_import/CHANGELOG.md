# Changelog

## 15.0.0
- Start productieontwikkeling van de officiële rapportgeneratoren.
- Eén guarded financiële productiecontext voor managementpagina, financiële KPI's, financiële simulatie, jaarprognose en maandtermijncontrole.
- Prognoses blijven geblokkeerd tot minimaal 7 waargenomen dagen.
- Leverancier-all-in blijft uitsluitend gebaseerd op gevalideerde officiële NextEnergy-contractwaarden.
- Ontbrekende financiële waarden blijven `Niet beschikbaar`; nooit automatische nulwaarden.
- EPEX blijft uitsluitend markt-/referentieprijs.
