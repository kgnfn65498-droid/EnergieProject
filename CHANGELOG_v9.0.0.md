# Changelog v9.0.0

- Eerste productieplatform-hoofdrelease op basis van de geslaagde v8.19.1-keten.
- Versie doorgezet naar 9.0.0 in Home Assistant metadata, runtime en statische regressietests.
- Productiecertificaat blijft versiegebonden: v9.0.0 vereist dus één eigen veilige productietest in Home Assistant.
- Recovery, Monitoring, Audittrail en Retry Debug tonen automatisch v9.0.0.
- Geen functionele wijziging aan centrale maandworkflow, scheduler, retry-state, workflow-lock of officiële rapportgeneratoren.
- 8.x blijft als historische bouwreeks in de changelog behouden.
